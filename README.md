# GooKal - AI Health & Nutrition Assistant

แอปพลิเคชันบันทึกอาหาร คำนวณแคลอรี่ และวิเคราะห์โภชนาการอัจฉริยะด้วย AI (Google Gemini 2.5) พร้อมศูนย์สุขภาพครบวงจร (Holistic Health Center), วิเคราะห์โภชนาการแบบ Real-time ด้วย Google Search Grounding, โค้ช AI ส่วนตัว 24/7 และระบบวางแผนมื้ออาหารเพื่อสุขภาพ

## วิธีการรันโปรเจกต์ (Run Locally)

**ความต้องการของระบบ (Prerequisites):** Node.js 18+

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
2. กำหนด `GEMINI_API_KEY` ในไฟล์ `.env`
3. เริ่มต้นรันแอปพลิเคชัน:
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)
